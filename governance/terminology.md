# 术语口径

核验基线：md2wechat `v3.1.0`，commit `f9af7a9110b2b472c8fc3fd9a3103863f6bf3862`，2026-07-14。

## 产品与接口

- **md2wechat**：将 Markdown 转为微信公众号可用 HTML，并提供预览、检查、图片、标题和草稿工作流的 CLI。
- **Guide**：面向使用者的任务手册，不保存完整上游命令参考。
- **API**：公开稳定转换接口以 [API 文档](https://www.md2wechat.cn/api-docs) 为准。
- **Skill**：供 Agent 读取的运行协议。执行前应使用 `md2wechat skills read md2wechat --json` 获取当前内容。

## 主题

- **主题目录总数**：发现结果中的全部条目，包含不可直接选择的内部默认条目。
- **可选主题**：用户可以在转换时选择的主题。
- **API 主题**：API 模式提供的主题。
- **AI 主题**：本地 AI 模式提供的主题。

当前发现结果为 53 个目录条目、52 个可选主题，其中 API 主题 48 个，AI 主题 4 个。数字变化时更新事实登记，正文优先引导用户运行 `themes list`。

## 高级排版

- **主推场景条目**：Agent 选型时看到的具体表达场景，当前 68 个。
- **主推语法名**：写进 Markdown 的推荐指令名，当前 53 个。
- **渲染语法能力**：渲染层覆盖的全部语法能力，当前 60 项。
- **兼容模块**：为旧稿或特殊场景保留的兼容入口，当前 3 个。
- **基础增强**：KaTeX、Mermaid、GFM Alert 等基础能力，当前 4 个。

对外出现数字时必须带上对应名词，不能统一写成“模块数量”。
