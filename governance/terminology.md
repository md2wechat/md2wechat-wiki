# 术语说明

当前数量以 md2wechat `v3.4.0`（commit `07fdea284e71ddaf5c6b5311238d7e9c2df3b8af`）为准。

## 产品

- **md2wechat**：面向 AI Agent 的微信公众号创作与发布 CLI。
- **Skill**：随核心产品提供、供 Agent 读取的运行协议。
- **Convert API**：把 Markdown 转成微信兼容 HTML 的服务；不创建公众号草稿。
- **Publishing API**：提供素材上传和草稿创建的服务。创建草稿不等于发送或群发。
- **在线编辑器**：用于人工编辑、预览和复制 HTML 的交互界面。

## 主题与高级排版

- **API 主题（48）**：API 模式提供的主题。
- **推荐场景（77）**：内容用途到推荐排版的映射。同一语法可以服务多个场景。
- **推荐语法名（56）**：`layout list --json` 默认返回、供新内容选择的语法对象。
- **兼容模块（3）**：为旧稿迁移保留的入口。
- **基础增强（4）**：KaTeX、Mermaid、GFM Alert 等基础渲染能力。
- **渲染语法能力（63）**：56 个推荐语法名、3 个兼容模块和 4 个基础增强能力的合计。

## 平台验证状态

- **`verified`**：已保存完整 smoke 证据，包括安装、CLI 可见、版本、能力、检查和预览；如果公开声称草稿能力，还需完成用户授权后的草稿闭环。
- **`compatible`**：已完成与目标宿主相关的兼容性验证。
- **`install-ready`**：安装机制或包格式已确认，真实宿主 smoke 尚未完成。
- **`smoke-pending`**：已进入验证队列，安装和运行结果仍待确认。
- **`unsupported`**：已有证据表明当前无法使用。
- **`review-due`**：证据已超过复核期或条件发生变化，需要重新检查。

只有 `verified` 或 `compatible` 可以设置 `publiclySupported=true`。
